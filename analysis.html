Framing analysis

How the newsrooms frame the same story

For each group of articles about one event, an AI model reads the headlines and summaries, scores how far apart the framings are, and suggests possible reasons. Scores run from 0, where outlets describe the event in much the same tone, to 100, where the framings are sharply opposed.

These are readings of the text shown, not verdicts on any outlet. The model can be wrong, and "possibly" in a reason marks a guess. Outlet names are shown here, which is why this page is kept apart from the game.
